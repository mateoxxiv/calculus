## Estructura del proyecto

```bash
.
├── 00_temporary/             # Notas en proceso de consolidación
├── 01_concepts/              # Conceptos matematicos consolidados
└── 02_examples/              # Ejemplos de conceptos
```

### **00_temporary**
Todas las notas inicialmente se asignan a esta carpeta en su proceso de creación, una vez se tenga la nota consolidada se pasa a **01_concepts**

### **01_concepts**
Tenemos los conceptos relevantes en el calculo como funciones y limites

### **02_examples**
Ejemplos de los conceptos que se explican en **01_concepts**
