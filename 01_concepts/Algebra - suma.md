#Operaciones_Algebraica

>[!info]
>Es la **operación matemática** que consiste en **combinar dos o más cantidades** para obtener una **cantidad total**.

# Propiedades

| Propiedad       | Descripción breve                          | Expresión matemática                 |
| --------------- | ------------------------------------------ | ------------------------------------ |
| Conmutativa     | El orden no cambia la suma                 | $(a + b = b + a)$                    |
| Asociativa      | La forma de agrupar no cambia el resultado | $(a + b) + c = a + (b + c)$          |
| Elemento neutro | Sumar cero no altera el número             | $(a + 0 = a)$                        |
| Inverso aditivo | Un número más su opuesto da cero           | $(a + (-a) = 0)$                     |
| Clausura        | La suma pertenece al mismo conjunto        | Si $(a, b \in A), \to (a + b \in A)$ |
