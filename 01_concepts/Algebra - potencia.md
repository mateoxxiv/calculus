#Operaciones_Algebraica 

>[!info]
>Es una **operación matemática** que representa la **multiplicación repetida** de un mismo número, llamado **base**.

# Propiedades

| Propiedad                | Descripción breve                           | Fórmula                                                                                 |
| ------------------------ | ------------------------------------------- | --------------------------------------------------------------------------------------- |
| Definición               | Multiplicación repetida de una base         | $a^n = \underbrace{a \cdot a \cdot \ldots \cdot a}_{n\text{ veces}},; n \in \mathbb{N}$ |
| Exponente cero           | Toda base distinta de cero elevada a 0 es 1 | $a^0 = 1,; a \neq 0$                                                                    |
| Exponente uno            | Toda base elevada a 1 es la misma base      | $a^1 = a$                                                                               |
| Exponente negativo       | Eleva al inverso de la base                 | $a^{-n} = \frac{1}{a^n},; a \neq 0$                                                     |
| Producto de potencias    | Se suman los exponentes                     | $a^m \cdot a^n = a^{m+n}$                                                               |
| Cociente de potencias    | Se restan los exponentes                    | $\frac{a^m}{a^n} = a^{m-n},; a \neq 0$                                                  |
| Potencia de una potencia | Se multiplican los exponentes               | $(a^m)^n = a^{m\cdot n}$                                                                |
| Potencia de un producto  | El exponente se distribuye                  | $(ab)^n = a^n b^n$                                                                      |
| Potencia de un cociente  | El exponente se distribuye                  | $\left(\frac{a}{b}\right)^n = \frac{a^n}{b^n},; b \neq 0$                               |
