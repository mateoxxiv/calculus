#Función 

>[!info]
>Es una función de grado a
# Ecuación
$$y = f(x) = x^a$$

- $a$: es un valor constante

# Casos
Nuestra función puede tomar diferentes formas dependiendo de los valores que le pasemos a nuestro parámetro $a$

| Caso             | Característica                                 |
| ---------------- | ---------------------------------------------- |
| $a >= 1$ y par   | Tienen forma de una curva cóncava y simétrica  |
| $a >= 1$ e impar | Tienen forma de una curva conexa  y asimétrica |
| $0 < a >= 1$     | Toma forma de raíz, si es impar es asimétrica  |
| $0 > a$          | Por propiedad x pasa a ser denominador         |
