#Función 

>[!info]
>Podemos combinar dos funciones tal cual como hacemos con las operaciones de números reales para dar origen a una nueva función.

# Operaciones permitidas

1. Suma $(f + g)(x) = f(x) + g(x)$
2. Multiplicación $(f * g)(x) = f(x) * g(x)$
3. Compuestas $f(g(x))$

# Propiedades

Supongamos que el dominio de $f$ es $A$ y el de $g$ es $B$, tenemos que.

1. El dominio de ambas funciones combinadas es la intercepción entre A y B
2. Para las funciones compuestas el dominio consta de todos los valore de $x$ que están disponibles en $B$ y luego en $A$
