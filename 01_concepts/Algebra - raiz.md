#Operaciones_Algebraica 

>[!info]
>La **raíz** es la **operación matemática inversa de la [[Algebra - potencia]]**.

# Propiedades

| Propiedad            | Descripción breve                                 | Fórmula                                                              |
| -------------------- | ------------------------------------------------- | -------------------------------------------------------------------- |
| Definición           | Número que elevado a (n) da (a)                   | $\sqrt[n]{a} = b ;\Leftrightarrow; b^n = a$                          |
| Raíz cuadrada        | Caso particular con índice 2                      | $\sqrt{a} = a^{1/2},; a \ge 0$                                       |
| Raíz como potencia   | Raíz expresada con exponente fraccionario         | $\sqrt[n]{a} = a^{1/n}$                                              |
| Producto de raíces   | La raíz del producto es el producto de las raíces | $\sqrt[n]{ab} = \sqrt[n]{a}\sqrt[n]{b}$                              |
| Cociente de raíces   | La raíz del cociente es el cociente de las raíces | $\sqrt[n]{\frac{a}{b}} = \frac{\sqrt[n]{a}}{\sqrt[n]{b}},; b \neq 0$ |
| Raíz de una potencia | Se simplifica el exponente                        | $\sqrt[n]{a^m} = a^{m/n}$                                            |
| Raíz de raíz         | Se multiplican los índices                        | $\sqrt[m]{\sqrt[n]{a}} = \sqrt[mn]{a}$                               |
| Dominio (índice par) | Solo números no negativos                         | $\sqrt[n]{a}$ definida para $a \ge 0$ si $n$ es par                  |
