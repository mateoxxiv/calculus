#Función 

>[!info]
>Cuando nos enfrentamos a un problema en el que debemos modelar el comportamiento de un fenómeno, normalmente seguimos una secuencia de pasos para lograrlo.

# Proceso

1. Identificamos un problema del mundo real
2. Formulamos un modelo matemático:
	- Nombramos las variables.
	- Asumimos supuestos que simplifican nuestro problema.
3. Usamos nuestros conocimientos en física ó recolectamos datos para obtener una ecuación y sacamos conclusiones
4. Sacamos predicciones del mundo real
